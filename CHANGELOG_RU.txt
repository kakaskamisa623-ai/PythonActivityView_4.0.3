PYTHON ACTIVITY VIEW — CHANGELOG
================================

4.0.3 — Чтение активных браузеров
- Добавлено прямое read-only подключение к открытым базам истории Chrome/Edge/Brave/Opera/Vivaldi/Firefox.
- Для согласованного чтения используется явная SQLite-транзакция; SQLite сама учитывает committed
  записи WAL, поэтому браузер можно оставить открытым и продолжать работу.
- Источник открывается с mode=ro и PRAGMA query_only=ON; база не открывается на запись,
  не меняются настройки браузера, процессы не закрываются и не останавливаются.
- Если live read-only подключение недоступно, выполняется ограниченная попытка SQLite Backup API.
- В отчёте для источника записывается способ чтения: live_readonly или sqlite_backup.
- Уменьшены интервалы SQLite busy timeout в резервном пути, чтобы отмена/дедлайн
  быстрее возвращали управление сканеру.
- Добавлены 3 теста: чтение committed WAL при открытом writer, полный browser scan
  при активной базе и fallback на Backup API. Общее количество тестов — 106.
- Тесты активной SQLite-базы выполнены на синтетической WAL-базе в Linux; реальный Windows
  Chrome/Edge и собранный Windows EXE всё ещё требуют проверки на целевой системе.

4.0.2 — Ограничение времени и прогресс браузерного анализа
- Добавлен конечный тайм-аут на профиль браузера (по умолчанию 35 секунд) и общий тайм-аут
  отдельной проверки (180 секунд).
- SQLite Backup API копирует БД небольшими пакетами и сообщает о прогрессе по страницам и МБ.
- Долгие SQL-запросы прерываются через SQLite progress handler с проверкой отмены/дедлайна.
- Медленный профиль помечается timeout; оставшиеся профили продолжают проверяться.
- При исчерпании общего лимита оставшиеся профили помечаются not_scanned, а не not_found.
- В интерфейсе отображаются индекс профиля, имя браузера/профиля, размер БД и этап обработки.
- Счётчик переименован в «проверено источников», чтобы не воспринимался как процент завершения.
- Итог браузерного анализа уточняет проблемные/не найденные/пропущенные варианты. Число 14
  может означать 14 отсутствующих стандартных вариантов при одном найденном браузере.
- Добавлено 7 тестов на тайм-аут, прерывание SQL, продолжение после проблемного профиля,
  общий лимит и сообщения прогресса. Общее число тестов — 103.
- Реальные профили Windows и Windows EXE в этой среде не проверялись.

3.4.1 — Массовый ввод доменов и URL
- Поле пользовательских категорий браузерных доменов принимает одну или несколько ссылок.
- Поддерживаются разделители: запятая, точка с запятой, вертикальная черта, новая строка
  и двоеточие между ссылками; форматы «ссылка 1 : ссылка 2», «site1.example:site2.example»
  и URL1:URL2 разбираются автоматически.
- Двоеточия схемы URL и числовые порты сохраняются; повторяющиеся домены устраняются.
- Некорректные фрагменты отдельно учитываются, а интерфейс показывает сводку добавлений.
- Добавлены тесты пакетного разбора, IDN/кириллических доменов, дубликатов и портов.

3.4.0 — Навигация, поддержка кириллицы и статический разбор DLL
- Переработана навигация без смены цветовой схемы: 6 основных разделов и короткие
  вложенные вкладки вместо одной длинной горизонтальной полосы из 19 пунктов.
- Параметры проверки перенесены в две строки, действия отделены от заголовка;
  размер окна рассчитывается по разрешению экрана и не должен обрезать панель действий.
- Добавлен совместимый декодер UTF-8/BOM, UTF-16, CP1251, CP866 и активной Windows ANSI code page.
  Он применяется к текстовым историям, PowerShell/CMD-текстам, а Python-исходники
  читаются с учётом PEP 263 и резервным декодированием старых кириллических файлов.
- Unicode-пути и имена файлов сохраняются в отчётах; поисковые сравнения остаются
  Unicode-aware через casefold.
- Статический PE/DLL-анализ расширен: архитектура, PE32/PE32+, флаги DLL/ASLR/DEP/CFG,
  точки входа, секции, энтропия, импорты, экспорты, строки ASCII/UTF-8/CP1251/UTF-16LE.
- Добавлены контекстные индикаторы API-групп (память процессов, удалённые потоки/APC,
  ввод/хуки, графика/оверлеи, сеть) и обзор подозрительных для ручной проверки секций.
  Эти индикаторы не являются вердиктом и не подтверждают фактический вызов API.
- При установленном Capstone отображается ограниченный листинг машинных инструкций
  из исполняемых секций; встроенного восстановления оригинального C/C++ нет.
  Без Capstone остаются доступными заголовки, импорты, экспорты и строки.
- Добавлено отдельное окно DLL/PE с вкладками обзора, секций, импортов, экспортов,
  строк и машинного кода, а также экспортом JSON. Файл никогда не запускается.
- Добавлены тесты кириллического CP1251/CP866/UTF-8 текста, OEM-вывода системных
  команд, Unicode-имён и PE DLL; полный тестовый набор содержит 75 проверок.
- Проверен запуск GUI под Linux/Xvfb. Работа Windows UAC, кодовых страниц реальной Windows
  и сборка EXE требуют отдельной проверки на Windows.

3.0.0 — Готовность аудита, полнота и оценка доказательств
- Добавлена вкладка «Готовность и полнота»: текущие настройки Audit Policy, состояние
  каналов Event Log, включение командной строки для события 4688, настройки PowerShell
  Script Block/Module Logging, наличие службы Sysmon и возможности локальной среды.
- Перед основным сбором формируется снимок готовности; проверку можно повторить вручную.
  Утилита ничего не включает и не меняет в системных политиках.
- Для событий сохраняются исходная временная метка, локальное представление и UTC.
  Временные метки без смещения часового пояса явно помечаются как интерпретированные
  по локальному часовому поясу системы; исходная строка остаётся неизменной.
- Для каждой записи добавлена оценка класса источника и пояснение, что именно он подтверждает
  и чего не подтверждает. Сохранённый текст команды не выдаётся за доказательство успешного
  выполнения; остаточные фрагменты маркируются как низкодостоверные.
- Добавлено консервативное сопоставление процессов по Parent PID/ProcessId, ProcessGuid и
  сохранённым ID сессии. Связи только по PID маркируются как менее надёжные из-за повторного
  использования PID. Временная близость сама по себе не считается причинной связью.
- Добавлен отчёт о покрытии источников: проверено, обнаружено, отключено/не настроено,
  недоступно, не найдено, неизвестно и неприменимо. Вместо вводящего в заблуждение процента
  показываются счётчики и ограничения.
- Добавлена проверка совместимости Windows/Python/Tkinter и текущего часового пояса.
- CSV/JSON/HTML, снимки и ZIP-отчёт включают UTC/локальное время и оценки источников.
- ZIP-отчёт может по отдельному подтверждению включить копии доступных исходных файлов и
  экспортируемые EVTX-журналы через wevtutil epl. Копии ограничены по размеру; оригиналы
  не очищаются и не изменяются. Для копий рассчитываются SHA-256 исходника/копии.
- Добавлены 13 тестов v3; общий набор содержит 25 модульных тестов.

ОБЩИЕ ОГРАНИЧЕНИЯ
- Команды интерактивного Python нельзя восстановить только по событию создания процесса.
- Аудит Windows, Sysmon и журналирование PowerShell должны быть включены до проверяемых действий.
- Утилита читает только текущий компьютер и не выполняет скрытый перехват ввода.
