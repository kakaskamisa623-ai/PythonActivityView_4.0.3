Python Activity View 4.0.1 — исправления браузерной истории и отмены сканирования
================================================================================

1. Добавлена отдельная кнопка «Сканировать историю браузеров» на вкладке истории.
   Она запускает только анализ браузеров текущего пользователя и не требует
   повторного запуска полного системного сканирования.

2. Чтение истории браузеров по-прежнему не включается скрытно при обычном старте.
   Нажатие отдельной кнопки является явным согласием на чтение локальных URL,
   заголовков посещений и метаданных загрузок. Пароли, cookies и переписка не читаются.

3. Исправлена отмена анализа браузеров: проверка отмены теперь выполняется во время
   SQLite backup и при обходе записей посещений и загрузок. Большие истории больше
   не должны удерживать состояние сканирования до завершения всего профиля.

4. После получения результата отмены, ошибки или завершения сканирования все основные
   кнопки возвращаются в корректное состояние. Новый запуск доступен после завершения
   отмены предыдущего рабочего потока; параллельные проверки не запускаются.

5. Улучшено обнаружение профилей:
   - USERPROFILE используется как основной путь профиля Windows;
   - добавлены профили Chrome Beta/Dev/Canary и Edge Beta/Dev/Canary;
   - добавлены известные расположения Yandex Browser;
   - поддержаны относительные и абсолютные пути Firefox из profiles.ini;
   - расширена поддержка Unicode-путей.

6. SQLite source открывается по корректному file URI (включая пробелы и Unicode),
   read-only и копируется через SQLite Backup API во временную папку. Исходная база
   не изменяется приложением.

7. Полный системный скан также передаёт проверку отмены внутрь browser history scanner.

Тесты:
- 96 модульных тестов пройдено после внесения исправлений.
- Синтетическая Chromium History с URL и кириллическим заголовком прочитана.
- Проверено обнаружение профилей Chrome и Firefox с абсолютным и относительным путём.
- Проверена отмена во время чтения истории.
- Проверено повторное планирование GUI poller.
- Проведена ручная GUI-интеграционная проверка отмены, повторного запуска и отображения события.

Ограничение:
Реальные профили, запущенные браузеры, Windows ACL, UAC и собранный EXE требуют
дополнительной проверки на Windows 10/11. Нестандартные portable-профили, не
зарегистрированные в известных стандартных каталогах, могут потребовать отдельного
выбора профиля в будущей версии.
