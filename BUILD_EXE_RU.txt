СБОРКА PYTHON ACTIVITY VIEW 4.0.3 В ОДИН EXE
============================================

ТРЕБОВАНИЯ
----------
- Windows 10/11.
- Python 3.10 или новее с Tkinter/Tcl-Tk.
- pip для установки PyInstaller.
- Для включения дополнительных парсеров — соответствующие пакеты ниже.

БАЗОВАЯ СБОРКА
--------------
1. Распакуйте весь проект в отдельную папку.
2. Откройте эту папку и запустите BUILD_EXE.bat.
3. Скрипт проверит Python/Tkinter, запустит весь набор из 106 модульных тестов и при необходимости
   установит PyInstaller.
4. После успешной сборки файл появится здесь:
       dist\PythonActivityView.exe

Вручную:
    python -m pip install --upgrade pyinstaller
    python -m unittest -v test_pav250.py test_pav300.py test_pav310.py test_pav320.py test_pav330.py test_pav340.py test_pav400.py test_pav401.py test_pav402.py test_pav403.py
    python -m PyInstaller --noconfirm --clean PythonActivityView.spec

НЕОБЯЗАТЕЛЬНЫЕ ПАРСЕРЫ
----------------------
Базовая программа работает без этих пакетов. Устанавливайте только то, что требуется:

    python -m pip install python-evtx python-registry LnkParse3
    python -m pip install dissect.database
    python -m pip install pefile capstone
    python -m pip install reportlab
    python -m pip install dissect.target
    python -m pip install git+https://github.com/ANSSI-FR/dfir-jumplist-parser.git

Пакеты должны быть установлены ДО сборки EXE, иначе PyInstaller их не включит. Spec пытается
добавить соответствующие динамические импорты только при наличии библиотек в среде сборки.
Установите только необходимые parser packages: Dissect может заметно увеличить размер EXE.
ANSSI Jump List parser — beta; его схема и API могут меняться.

UAC И ПРАВА
-----------
Манифест сборки не требует обязательного администратора (asInvoker). Обычная проверка
запускается без повышения; пункт повышения прав в интерфейсе вызывает стандартный UAC
Windows только по явному действию пользователя. Автоматический UAC остаётся настройкой.

ВСТРОЕННАЯ КОНСОЛЬ СЕССИИ
------------------------
В EXE встроенный процесс записи сессии запускается повторным запуском этого же EXE в
служебном pipe-режиме --pav-session-worker. Это не требует Python на проверяемом ПК.
Код во встроенной консоли выполняется с правами пользователя и не является песочницей.

КЛАВИАТУРНЫЕ СОЧЕТАНИЯ
----------------------
- Ctrl+C / Ctrl+X / Ctrl+V — копировать / вырезать / вставить в поля ввода и заметки;
  в таблицах Ctrl+C копирует выбранные строки.
- Ctrl+A — выделить всё; Ctrl+Z / Ctrl+Y — отменить / повторить в редактируемом тексте.
- Ctrl+Shift+C — скопировать подробности выбранной записи.
- Ctrl+O — импортировать EVTX; Ctrl+R или F5 — начать проверку.
- Ctrl+S — CSV; Ctrl+Shift+S — JSON; Ctrl+Shift+E — ZIP-пакет доказательств.
- Ctrl+Tab / Ctrl+Shift+Tab — следующая / предыдущая вкладка; Esc — очистить общий поиск.
- Правая кнопка мыши по редактируемому полю открывает контекстное меню.

ПРОВЕРКА ПОСЛЕ СБОРКИ
--------------------
- Запустите EXE обычным пользователем и проверьте сканирование/отмену.
- Проверьте чтение браузеров только после явного согласия.
- Проверьте все сочетания клавиш на полях ввода, заметках и таблицах.
- Проверьте импорт тестового EVTX и вывод «parser unavailable», если python-evtx не встроен.
- Проверьте экспорт/импорт .pavcase, SHA-256 реестра доказательств и отказ от повреждённого пакета.
- Проверьте Ctrl+F по кириллице/regex, сравнение двух файлов и PDF экспорт с Unicode шрифтом.
- На тестовых копиях проверьте статический анализ, Prefetch, Amcache, SRUM, LNK и Jump Lists.
- Проверьте профили сканирования, фильтр артефактов, граф связей, тепловую карту, сохранение
  и открытие дела, добавление/проверку SHA-256 доказательств, импорт/экспорт .pavcase,
  Ctrl+F глобальный поиск, сравнение двух файлов, PDF (при установленном ReportLab),
  диагностику, доверенный контекст и CSV/JSON/HTML/ZIP экспорт.
- Проверьте запуск, UAC и поведение frozen EXE на чистой Windows без Python/PyInstaller.
- Проверьте каждый optional parser с эталонными образцами соответствующей версии формата.

ОГРАНИЧЕНИЯ
-----------
Разработка и текущие тесты выполнялись в Linux. Windows Event Log, UAC, Sysmon, wevtutil,
реальные профили браузеров и frozen one-file EXE не проверены на реальной Windows в этой
сессии. Наличие parser пакета не подтверждает точность всех его версий; результаты Prefetch,
SRUM и Jump Lists нужно сверять по независимым источникам. Программа не запускает файлы,
не устанавливает службы, не перехватывает трафик/клавиатуру и не меняет исследуемые базы.

ДОПОЛНЕНИЯ ВЕРСИИ 4.0.0 И ИСПРАВЛЕНИЯ 4.0.1
-----------------------
- В переносимом деле .pavcase используется manifest.json с SHA-256 файлов пакета; проверка
  манифеста и безопасных путей выполняется до импорта. Это контроль целостности, не цифровая
  подпись издателя или доверенная метка времени.
- PDF-экспорт требует ReportLab и доступный локальный Unicode TrueType шрифт. Для установки:
      python -m pip install reportlab
- Для реестра доказательств выбираются только конкретные файлы. Программа копирует их в
  хранилище дела, сверяет хеш копии и при дальнейшей проверке сообщает о несоответствиях.
- Глобальный Ctrl+F ищет только по данным, уже загруженным в текущем сеансе приложения.
- Сборка EXE в one-file содержит только необязательные парсеры, установленные в окружении
  сборки. Сверьте список библиотек и результат сборки на чистой целевой Windows.


ИСПРАВЛЕНИЯ ВЕРСИИ 4.0.1
------------------------
- На вкладке Browser History добавлена отдельная кнопка «Сканировать историю браузеров».
  Она запускает только чтение профилей текущего пользователя; обычный полный скан сохраняет
  исходное поведение opt-in и не читает браузерную историю без включённого флажка.
- Добавлена отмена во время SQLite Backup API и обхода строк посещений/загрузок.
- После получения завершающего события done/cancelled/error элементы управления возвращаются
  в состояние готовности; новый скан можно запускать после завершения старого рабочего потока.
- Улучшено обнаружение стандартных профилей Chrome/Edge/Brave/Opera/Chromium/Vivaldi/Yandex
  и профилей Firefox из profiles.ini, включая относительные и абсолютные пути.
- SQLite-источник открывается read-only через URI, а рабочая копия создаётся во временном
  каталоге; сканер не записывает данные в исходную историю браузера.
- Перед выпуском проверьте чтение профилей, пока браузеры открыты и закрыты, на целевой
  Windows 10/11: доступность History/WAL/SHM зависит от состояния профиля и ACL.
