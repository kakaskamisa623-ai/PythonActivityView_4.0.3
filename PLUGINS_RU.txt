ПЛАГИНЫ PYTHON ACTIVITY VIEW 3.4.1
==================================

Пример безопасного шаблона находится в example_readonly_plugin.py.
Скопируйте его в пользовательскую папку и измените только после проверки исходного кода.

Папка плагинов находится в пользовательском каталоге данных приложения:
    %APPDATA%\PythonActivityView\plugins

Формат модуля
-------------
Каждый плагин — отдельный файл .py. Для загрузки он должен объявлять словарь PAV_PLUGIN
и функцию analyze(context), возвращающую dict:

    PAV_PLUGIN = {
        "name": "Example read-only plugin",
        "version": "1.0",
        "read_only": True,
    }

    def analyze(context: dict) -> dict:
        events = context.get("events", [])
        return {
            "summary": "Плагин просмотрел переданный список событий",
            "event_count": len(events),
        }

Обнаружение модулей в интерфейсе читает только имена файлов и не импортирует код.
Программный API pav_plugins.PluginRegistry.load(filename, approved=True) требует явного
параметра подтверждения; затем run(filename, context) вызывает analyze(context).

БЕЗОПАСНОСТЬ
------------
- Python-плагин — исполняемый код, а не изолированный расширяемый формат.
- Загруженный модуль наследует все права процесса Python Activity View (включая UAC, если
  приложение запущено с повышением).
- Флаг read_only — декларация автора, а не техническая песочница или гарантия.
- Не загружайте неизвестные плагины и не используйте их на компьютере проверяемого лица.
- Плагины не должны менять системные артефакты, удалять журналы, собирать пароли,
  перехватывать ввод или отправлять результаты по сети.
- Перед использованием изучите исходный код и ограничьте context только необходимыми данными.
- Отключение плагина означает не загружать его; удалите файл вручную из папки plugins.

Плагинная система намеренно не загружает файлы автоматически при старте приложения.
